# Phase 4 Plan 03: Linked timeline investigation, log lines, and error signatures

## Phase Goal

ROADMAP Phase 4 goal (verbatim): "Make the analysis useful in the browser through one-click case studies, an evidence-first verdict, linked timeline investigation, and recoverable accessible states."

## Planning decisions honored

Decision IDs are the planner-assigned IDs from Plan 04-01.

- D-01: hand-authored SVG and native CSS; no chart library.
- D-02: log lines, bucket signature counts and event ids come from the kept `AnalysisStream` (`buckets`, `normalizedEvents`, `errors`), which `toAnalysisResult` drops.
- D-05: SVG built with `svgEl` (`createElementNS` + `setAttribute`), text through `textContent`; tooltip and labels are text nodes.
- D-12 (UI-SPEC Data Visualization Contract): three categorical jobs only (errors `--viz-series-errors`, onset `--viz-onset`, leading suspect `--viz-suspect`) plus context gray; colour follows the entity, never rank; text never wears series colour; legend always shown with mark-shaped keys; table twin is the non-pointer equivalent of every chart value.
- D-13 (UI-SPEC Interaction): tooltips enhance and never gate; the readout bar and table twin always carry the same values; default selection is the onset bucket or the peak.
- D-09: no transitions; forced-colors and print use a hatch pattern for the onset band.

Planner discretion (recorded here so the checker sees it):

- Log panel scope: opened from the slider, readout button or a table-twin row it shows the selected interval's events intersected with the active signature filter; opened from a signature toggle (or, in Plan 04-04, from the drawer) it shows all events of that signature. The header names the scope.
- Opening the log panel moves focus to its heading (`tabindex="-1"`); "Close log lines" returns focus to the opener, or to the slider if the opener was re-rendered.
- Filtered readout reads `{filtered} of {total} errors`; the table twin Errors column shows the filtered count while a filter is active.
- Commits after the view's right edge get the parallel note "N later commits are outside this view; see Commits considered." beside the specified earlier-commits note.
- An analysis with zero buckets renders the text "No error intervals to plot." in place of the chart.
- Commit markers are drawn here as marks only; making the top three focusable buttons that open the suspect drawer is Plan 04-04 Task 2, which ships the drawer.

Edge-coverage source: spec-less fallback; edge predicates come from the UI-SPEC "UI Considerations" table and the ROADMAP Phase 4 success criteria.

<objective>
Add the linked investigation surface: an accessible shared-time-axis timeline that connects error rate, onset window, commits and the highlighted leading suspect (UX-03); a non-hover path from any interval or error group to the underlying log lines (UX-04); and an error-signature table that filters the timeline (UX-06), all keyboard-operable and usable at phone width (UX-09).

Purpose: lets a person verify the verdict against the evidence instead of trusting it.
Output: pure geometry and investigation-model modules with tests, and the timeline, log lines and signature renderers wired into the console.
</objective>
