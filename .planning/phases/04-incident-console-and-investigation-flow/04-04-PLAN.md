# Phase 4 Plan 04: Linked timeline investigation and log lines

## Phase Goal

ROADMAP Phase 4 goal (verbatim): "Make the analysis useful in the browser through one-click case studies, an evidence-first verdict, linked timeline investigation, and recoverable accessible states."

## Planning decisions honored

Decision IDs come from the register in Plan 04-01 plus two added here.

- D-01: hand-authored SVG and native CSS; no chart library.
- D-02: log lines and event ids come from the kept `AnalysisStream` (`buckets`, `normalizedEvents`), which `toAnalysisResult` drops.
- D-05: SVG built with `svgEl` (`createElementNS` + `setAttribute`); labels and tooltip are text nodes.
- D-09: no transitions; forced-colors and print use a hatch pattern for the onset band.
- D-12 (UI-SPEC Data Visualization Contract): three categorical jobs only (errors `--viz-series-errors`, onset `--viz-onset`, leading suspect `--viz-suspect`) plus context gray; colour follows the entity, never rank; text never wears series colour; the legend is always shown with mark-shaped keys; the table twin is the non-pointer equivalent of every chart value.
- D-13 (UI-SPEC Interaction): tooltips enhance and never gate; the readout bar and table twin carry the same values; default selection is the onset bucket or the peak.

Planner discretion (recorded for the checker):

- Opening the log panel moves focus to its heading (`tabindex="-1"`); "Close log lines" returns focus to the opener, or to the slider if the opener was re-rendered.
- Commits after the view's right edge get the parallel note "N later commits are outside this view; see Commits considered." beside the specified earlier-commits note.
- An analysis with zero buckets shows the text "No error intervals to plot." instead of the chart.
- Commit markers are drawn here as marks only; Plan 04-06 makes the top three focusable buttons when it ships the drawer they open.
- The signature table and filtering (UX-06) are Plan 04-05; this plan's investigation state carries no filter yet.

Edge-coverage source: spec-less fallback; edge predicates come from the UI-SPEC "UI Considerations" table and the ROADMAP Phase 4 success criteria.

Revision note (checker revision 1): this plan is Tasks 1-2 of the former Plan 04-03; the signature table and filter (its former Task 3) moved to Plan 04-05 to restore estimate headroom.

<objective>
Add the linked investigation surface: an accessible shared-time-axis timeline connecting error rate, onset window, commits and the highlighted leading suspect (UX-03), and a non-hover path from any interval to its underlying log lines (UX-04), keyboard-operable and usable at phone width (UX-09).

Purpose: lets a person check the verdict against the evidence instead of trusting it.
Output: pure geometry and investigation-model modules with tests, and the timeline and log-lines renderers wired into the console.
</objective>
