4. Create `src/core/scoring.ts`:

   - `export const SIGNAL_ORDER: readonly SignalName[] = ['proximity', 'trace-match', 'novelty', 'churn']` (frozen) and `export const EVIDENCE_LIMITS = Object.freeze({ logEvents: 3, groups: 5, files: 5 })`.
   - `export function round6(value: number): number` = `Math.round(value * 1e6) / 1e6`, mapping -0 to 0; `export function toMicro(value: number): number` = `Math.round(value * 1e6)`.
   - `export function proximityValue(gapMinutes: number): number`: returns 1 when `!(gapMinutes > 0)`; else `halfLives = gapMinutes / 60`, `whole = Math.min(Math.floor(halfLives), maxHalvings)`, halve a `scale` of 1 `whole` times in a loop, return `round6(scale * (1 - (halfLives - Math.floor(halfLives)) / 2))`. Exact knots: 12 min 0.9, 60 min 0.5, 120 min 0.25.
   - `export function churnValue(linesChanged: number, filesTouched: number): number` = `round6(0.7 * (lines / (lines + 50)) + 0.3 * Math.min(1, Math.max(0, files - 1) / (fileCap - 1)))`, returning 0 when both are 0.
   - `export interface CommitScore { sha: string; timeGapMinutes: number; score: number; traceValue: number; signals: SignalContribution[]; traceSummary: TraceSummary; evidenceReferences: EvidenceReference[]; }` and `export function scoreCommit(commit: GitCommit, index: EvidenceIndex, referenceUtc: TimestampUtc): CommitScore`. Throw `new Error('referenceUtc must be a valid UTC timestamp.')` only if `Date.parse(referenceUtc)` is not finite (internal invariant). `commitEpoch = Date.parse(commit.timestampUtc)`; `gap = Math.max(0, (referenceEpoch - commitEpoch) / 60000)`; `timeGapMinutes = round6(gap)`.
     - proximity: value `proximityValue(gap)`; one `feature` reference (sourceId = commit sha, path null, lines null, detail `<gap> min before onset window start <referenceUtc>`).
     - trace-match: for every `IndexedFrame`, `matchPath(frame.path, commit.files paths)`; on `exact`/`prefix-stripped` take that file, `classifyLine(frame.line, file.ranges, nearbyLines)`, `n = countAtOrAfter(frame.epochs, commitEpoch)` (events at or after the commit, inclusive); add `traceStrengthTenths[kind] * n` to an integer sum; value = `round6(sumTenths / (10 * totalErrorEvents))`, or 0 when `totalErrorEvents === 0`. Only the top application frame of each event is scored (research A6). Build one `file-range` reference per matched frame (sourceId sha, path = changed file path, lineStart/lineEnd = matched range or null for file-only, detail naming match kind, frame `path:line`, and `n of totalErrorEvents error events`), up to `EVIDENCE_LIMITS.groups` `error-group` references for signatures with matched events (sourceId = signature, detail `k of groupCount events match`; order matched desc then signature), and up to `EVIDENCE_LIMITS.logEvents` `log-event` references for the earliest matched events (sourceId = eventId, path/lines = frame path and line, detail with the event UTC time). `traceSummary`: best kind among frames with `n > 0` (exact-line > nearby-line > file-only > none), `matchedErrorCount` (events with strength > 0), `lineLevelErrorCount` (exact or nearby), `totalErrorCount`.
     - novelty: integer sum of `group.count` for groups with `firstSeenEpoch >= commitEpoch`, divided by `totalErrorEvents` and `round6`ed (0 when no errors). Aggregate over all groups (over-split signatures, research Pitfall 6). Up to `EVIDENCE_LIMITS.groups` `error-group` references ordered by firstSeenEpoch then signature, detail `first seen <UTC> (<count> events), at or after this commit`.
     - churn: in this tracer count every file: lines = sum of added + deleted, files = file count; value `churnValue`; up to `EVIDENCE_LIMITS.files` `file-range` references sorted by `compareText(path)` with lineStart = min range start, lineEnd = max range end (null when no ranges), detail `+added/-deleted lines`.
     - For each signal in `SIGNAL_ORDER`: `contribution = round6(value * weight)`; `score = round6(c0 + c1 + c2 + c3)` summed in `SIGNAL_ORDER` order so displayed contributions re-add to the score. `traceValue` = trace-match value. `evidenceReferences` = all signal references deduplicated by the key type|sourceId|path|lineStart|lineEnd|detail (first occurrence kept).
     - Explanations are one plain-language sentence each, built only from integers, `String(round6(x))`, UTC ISO strings and repository paths (no locale formatting). Proximity names the gap minutes, the reference timestamp, and that closeness halves every 60 min. Trace names `matched of total` error events and the matched path/lines. Novelty names `n of total` error events in signatures first seen at or after the commit. Churn names lines and files and that churn is bounded to at most 0.1 of the score. Never use the words "generated", "caused by", "the culprit is", or a percent sign (the existing Markdown test in `tests/core/analysis-fixture.test.ts` rejects the word "generated").
   - Arithmetic rule (D-07): only `+ - * /`, comparisons, `Math.floor`, `Math.round`, `Math.min`, `Math.max`, and the halving loop. No exponentiation operator and no Math exponential, logarithm, or power functions (they are implementation-approximated and differ across engines).
